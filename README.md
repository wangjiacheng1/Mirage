# Mirage 幻境 · AI 互动叙事客户端

> 一个 **纯客户端、无服务端(BYOK)** 的 AI 角色扮演 / 情景模拟 / 互动叙事应用。
> 用户自带大模型 API Key,App 负责角色卡、剧情编排、游戏状态与沉浸式体验。
> 技术形态:**Kotlin Multiplatform 共享业务层 + Android(Compose)UI**,iOS 留口但暂不实现。

---

## 0. 一句话定位

**"把大模型变成一个随身的 GM(游戏主持人)。"**
用户导入或创建一个角色/世界观,App 负责把它变成一场有状态、有记忆、能存档回档的互动故事。

| 项 | 决策 | 状态 | 影响 |

| 产品形态 | Android 原生 App(KMP 共享层) | ✅ 已确认 | Kotlin + Compose + KMP |
| 服务端 | **无**。纯客户端 | ✅ 已确认 | 无账号、无云同步、无服务端审核 |

| 发布渠道 | **暂不在任何应用商店发布**;若发布也不走国内渠道 | ✅ 已确认 | 合规、备案、法律咨询 **全部推迟/取消**;当前用 GitHub Release 分发 |

| 角色卡市场 | **明确不做**。改为把"导入"做到行业最好,寄生现有生态 | ✅ 已确认 | `B-3` 升为战略级 P0 |
| 盈利模式 | 待定(候选:买断 / 本地内购 / 开源+捐赠) | ⏳ 待确认 | 见 `docs/09` Q5 |
